Signals: what Violet and Aqua cannot say.

Momentum Violet and Flow Aqua sit sixty degrees apart in the same cool band, so the identity pair cannot encode done, due, overdue or blocked — and a task tool lives on exactly those states. Four supporting hues carry them, each supplied in two audited variants: one for light surfaces, one for dark.

Standing rule: Flow Aqua is a fill, not a foreground. At 1.92:1 against white it fails text contrast outright; used as a background with Dydan Ink on top it reaches 9.88:1. Documents take Deep Aqua instead, and state is never expressed by Violet or Aqua alone.

Logo application.

The current Dydan wordmark keeps the fixed colour relationship: Momentum Violet carries the word, Flow Aqua marks the y stem, and the y detail returns to Violet. Application surfaces do not create a second identity.

On light surfaces

Use the Dydan wordmark on light surfaces with its fixed Violet/Aqua relationship. Do not recolour, stretch, rotate, add glow, or replace the primary pair. WCAG exempts logotypes from text contrast minimums; surrounding interface content still follows the measured token rules.

On dark surfaces

The same wordmark may sit on dark application surfaces. Its primary identity pair remains unchanged; accessible supporting tints belong to interface content, not to a replacement logo identity.
