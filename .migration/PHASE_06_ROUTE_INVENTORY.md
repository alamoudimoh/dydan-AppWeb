# Phase 6 Route Inventory

Classification is based on `src/contexts/RouterContext.jsx` and the authoritative
Figma Make sources at `design-source/figma-make/src/screens/`. A means an exact
authoritative Figma screen. B means the route retains its product behavior while
using the literal Figma shell and reusable Figma primitives (`card`, `btn`,
`input`, `task-row`, `Section`, `Row`, `Toggle`, modal). C means there is no
authoritative Figma design for the route's information architecture and no visual
change is made.

## Owner Input Required

`/notifications` is the sole category C surface. The minimum required input is an
authoritative notification-center design covering unread/read rows, mark-all-read,
pagination/loading/error states and safe destination affordances. No replacement
UI was invented in this phase.
